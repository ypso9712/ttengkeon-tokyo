🌐 2. Vercel 무료 배포 & Firebase DB 연결 (대표 1명만 설정) 100% 평생 무료

제미나이 화면 안에서는 기본 클라우드로 즉시 작동합니다. 외부 링크(Vercel 등)로 배포할 때는 대표 1명만 무료 Firebase DB 주소를 발급받아 아래에 넣거나 코드 상단 HARDCODED_FIREBASE_DB_URL에 넣어두면 전원이 함께 쓸 수 있습니다.

💡 Vercel + Firebase 1분 무료 세팅법 (대표 1명만 하면 끝!)
  1. Firebase 무료 DB 생성: console.firebase.google.com 접속 ➔ 프로젝트 추가 ➔ 왼쪽 메뉴 [빌드] ➔ [Realtime Database] ➔ [데이터베이스 만들기] ➔ [테스트 모드에서 시작] 선택 후 상단 주소(https://...firebasedatabase.app) 복사
  2. Vercel 무료 호스팅 배포: HTML 파일을 다운로드해 이름을 index.html로 바꾼 뒤 vercel.com (또는 GitHub Pages)에 무료 업로드하여 사이트 주소 발급
  3. 단톡방 원클릭 공유: 배포된 사이트에서 위 칸에 DB 주소를 넣고 [🔗 친구 초대용 자동연결 링크 복사]를 눌러 카톡 단톡방에 올리면, 친구들은 그 링크만 눌러도 자동 연결됩니다!
